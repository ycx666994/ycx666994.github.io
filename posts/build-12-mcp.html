🔧 从零搭建12个MCP服务

📅 2026-05-08 | ⏱️ 阅读时间：约8分钟 | 📊 难度：中高级

📖 什么是MCP？

MCP（Model Context Protocol） 是 Anthropic 推出的 AI 工具调用协议，让 Claude Code 等 AI 能够与 MATLAB、Python、Simulink 等工具协同工作，实现自动化工作流。

💡 核心理念： 一次配置，所有 AI 工具都能调用你的软件生态。

💻 环境准备

# 检查版本
node -v               # 需要 >= 18
python --version      # 需要 >= 3.10

# 安装 Claude Code
npm install -g @anthropic-ai/claude-code

# 安装 MCP 依赖
pip install mcp httpx

📋 12个MCP服务清单

  • 🔴 MATLAB MCP - 脚本执行、参数调优
  • 🐍 Python MCP - 科学计算、绘图
  • 📊 Simulink MCP - 模型创建、仿真
  • 📝 LaTeX MCP - 公式渲染、论文
  • 🔧 Git & Doc MCP - 实验记录
  • 📓 Jupyter MCP - Notebook生成
  • 📚 RAG MCP - 知识检索
  • 📈 MLflow MCP - 实验追踪
  • 🤖 ROS2 MCP - 机器人接口
  • 📊 DAQ MCP - 数据采集
  • ⚙️ HIL MCP - 硬件在环
  • 🌐 Overleaf MCP - 在线协作

⚙️ 配置文件示例

mcp_servers.json：

{
  "mcpServers": {
    "matlab": {
      "command": "python",
      "args": ["C:/path/to/matlab_mcp_server.py"],
      "env": {"MATLAB_WORKSPACE": "C:/matlab_workspace"}
    },
    "python-sci": {
      "command": "python",
      "args": ["C:/path/to/python_mcp_server.py"],
      "env": {"PYTHON_WORKSPACE": "C:/python_workspace"}
    }
  }
}

✅ 验证MCP是否工作

启动 Claude Code 后，输入以下命令：

/mcp                    # 查看所有MCP服务
@matlab disp('hello')   # 测试MATLAB
@python-sci 1+1         # 测试Python

🐛 常见问题

  • MATLAB命令找不到 → 将MATLAB路径添加到系统 PATH
  • Python模块缺失 → pip install mcp httpx
  • 连接失败 → 检查 mcp_servers.json 中的路径是否正确
