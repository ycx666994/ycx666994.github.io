📐 四旋翼无人机动力学模型

四旋翼无人机是一个6自由度（6DOF）系统，包含3个位置自由度（x, y, z）和3个姿态自由度（φ, θ, ψ）。

📊 物理参数

参数符号数值单位
质量m1.5kg
臂长L0.25m
惯性矩 XIx0.0023kg·m²
惯性矩 YIy0.0023kg·m²
惯性矩 ZIz0.0040kg·m²

📝 动力学方程

位置动力学：
ddot_x = (cosφ·sinθ·cosψ + sinφ·sinψ) × F_total / m
ddot_y = (cosφ·sinθ·sinψ - sinφ·cosψ) × F_total / m
ddot_z = (cosφ·cosθ) × F_total / m - g

姿态动力学：
ddot_φ = (Iy - Iz)/Ix × dot_θ × dot_ψ + τ_φ / Ix
ddot_θ = (Iz - Ix)/Iy × dot_φ × dot_ψ + τ_θ / Iy
ddot_ψ = (Ix - Iy)/Iz × dot_φ × dot_θ + τ_ψ / Iz

🎯 ADRC控制器设计

ADRC（自抗扰控制）由三部分组成：

  • 跟踪微分器（TD） —— 安排过渡过程，提取微分信号
  • 扩张状态观测器（ESO） —— 估计状态和总扰动
  • 非线性状态误差反馈（NLSEF） —— 计算控制量

💻 ESO核心代码（MATLAB）

function u = adrc_control(y, y_ref, dt)
    persistent z1 z2 z3
    
    % 观测器误差
    e = z1 - y;
    
    % 扩张状态观测器更新
    z1 = z1 + dt * (z2 - beta01 * e);
    z2 = z2 + dt * (z3 - beta02 * fal(e, 0.5, delta) + b0 * u);
    z3 = z3 + dt * (-beta03 * fal(e, 0.25, delta));
    
    % 控制律
    u = (k1 * (y_ref - z1) - k2 * z2 - z3) / b0;
end

function f = fal(e, alpha, delta)
    if abs(e) > delta
        f = abs(e)^alpha * sign(e);
    else
        f = e / (delta^(1-alpha));
    end
end
