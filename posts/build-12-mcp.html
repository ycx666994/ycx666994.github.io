🔧 从零搭建12个MCP服务

2026-05-08 | 阅读时间：8分钟 | 难度：中高级

什么是MCP？

MCP（Model Context Protocol）是Anthropic推出的AI工具调用协议，让Claude Code等AI能够与MATLAB、Python、Simulink等工具协同工作。

环境准备

# 检查版本
node -v        # 需要 >= 18
python --version  # 需要 >= 3.10

# 安装 Claude Code
npm install -g @anthropic-ai/claude-code

# 安装 MCP 依赖
pip install mcp httpx

12个MCP服务清单

  • MATLAB MCP - 脚本执行、参数调优、变量读取
  • Python MCP - 科学计算、绘图、控制分析
  • Simulink MCP - 模型创建、仿真、线性化
  • LaTeX MCP - 公式渲染、论文生成
  • Git & Doc MCP - 实验记录、README生成
  • Jupyter MCP - Notebook生成、研究报告
  • RAG MCP - 知识检索、论文管理
  • MLflow MCP - 实验追踪、参数优化
  • ROS2 MCP - 机器人接口、节点生成
  • DAQ MCP - 数据采集、信号读取
  • HIL MCP - 硬件在环仿真
  • Overleaf MCP - 在线LaTeX协作

配置文件示例 (mcp_servers.json)

{
  "mcpServers": {
    "matlab": {
      "command": "python",
      "args": ["C:/path/to/matlab_mcp_server.py"],
      "env": {"MATLAB_WORKSPACE": "C:/Users/HP/matlab_workspace"}
    },
    "python-sci": {
      "command": "python",
      "args": ["C:/path/to/python_mcp_server.py"],
      "env": {"PYTHON_WORKSPACE": "C:/Users/HP/python_workspace"}
    }
  }
}

验证MCP是否工作

在Claude Code中输入：

/mcp                    # 查看所有MCP服务
@matlab disp('hello')   # 测试MATLAB
@python-sci 计算1+1     # 测试Python

常见问题

  • MATLAB命令找不到：将MATLAB路径添加到系统PATH
  • Python模块缺失：pip install mcp httpx numpy scipy matplotlib
  • 连接失败：检查mcp_servers.json中的路径是否正确
