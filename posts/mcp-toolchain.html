MCP协议：让AI与任意工具协同工作

2026-05-08 | 阅读时间：4分钟

什么是MCP？

MCP（Model Context Protocol）是Anthropic公司推出的AI工具调用协议，让AI能够与任何工具/API协同工作。

核心概念

  • MCP Server：提供具体功能的服务器
  • Tool：服务器暴露的可用工具
  • Client：调用工具的AI（如Claude Code）

本项目中搭建的12个MCP服务

  • MATLAB MCP - 科学计算与仿真
  • Python MCP - 数据分析与可视化
  • Simulink MCP - 模型仿真
  • LaTeX MCP - 论文排版
  • Git-Doc MCP - 版本管理
  • Jupyter MCP - 交互式报告
  • RAG MCP - 知识检索
  • MLflow MCP - 实验追踪
  • ROS2 MCP - 机器人控制
  • DAQ MCP - 数据采集
  • HIL MCP - 硬件在环
  • Overleaf MCP - 在线协作
